# نصب ایمن صف برداشت V14

این بسته فقط مسیر مستقل «ثبت نهایی اکسل → چک‌لیست موبایل» را تغییر می‌دهد. به موجودی، `InventoryBankTable`، سوابق خروجی، جدول برداشت روزانه و ثبت نهایی عادی دست نمی‌زند.

## ترتیب نصب

1. از فایل فعلی اکسل یک کپی پشتیبان بگیرید و همان فایل اصلی را باز کنید.
2. `Alt+F11` را بزنید. از پوشهٔ **Modules** روی `NebrasPickQueueV13` راست‌کلیک و ابتدا **Export File…** را برای نگهداری نسخهٔ قبلی بزنید.
3. روی همان `NebrasPickQueueV13` راست‌کلیک و **Remove NebrasPickQueueV13…** را بزنید. چون مرحلهٔ قبل خروجی گرفته‌اید، هنگام سؤال ذخیرهٔ مجدد، **No** را بزنید.
4. از منوی **File → Import File…**، فایل `NebrasPickQueueV14_SAFE.bas` را وارد کنید. نام داخلی آن عمداً همان `NebrasPickQueueV13` است تا دکمه‌ها و ثبت نهایی فعلی بدون تغییر کار کنند.
5. از منوی **Debug → Compile VBAProject** استفاده کنید. باید بدون پیام خطا تمام شود.
6. با `Alt+F8` فقط ماکروی `Nebras_Install_PickQueue_V13` را اجرا کنید. این کار تنها سربرگ‌های ایمنی صف موبایل را اضافه و متن دکمهٔ ارسال مجدد را اصلاح می‌کند.
7. فایل را با پسوند `.xlsm` ذخیره کنید، ببندید و دوباره باز کنید تا ماکروها فعال شوند.

## اثر عملی

- هر ثبت نهایی، همان دستهٔ تازه را در پس‌زمینه ارسال می‌کند؛ اکسل هنگام ارسال قفل نمی‌شود.
- پاسخ مبهم یا دیررس ابتدا با سرور تأیید می‌شود؛ تنها اگر واقعاً ثبت نشده باشد، حداکثر سه بار با فاصلهٔ کوتاه تکرار می‌شود.
- دکمهٔ ارسال مجدد فقط **آخرین دستهٔ ناموفق** را بررسی می‌کند؛ سفارش‌های قدیمی دوباره به موبایل فرستاده نمی‌شوند.
- شناسهٔ سفارش یکتا است؛ ارسال تکراری نمی‌تواند کارت قبلی یا وضعیت «برداشت شد/ناقص/مغایرت» آن را بازنویسی کند.

## مرحلهٔ بعدی لازم

پیش از آزمون، کد `apps-script/PickQueueV13.gs` باید در همان پروژهٔ Google Apps Script فعلی جایگزین و به صورت **New version** روی همان Web App موجود Deploy شود. تا وقتی آن مرحله انجام نشده، دکمه‌های جدید و تأیید سرور فعال نمی‌شوند.
